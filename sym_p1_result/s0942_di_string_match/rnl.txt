A permutation `perm` of `n + 1` integers of all the integers in the range `[0, n]` can be represented as a string param_s of length `n` where:
`s[i] == 'I'` if `perm[i] < perm[i + 1]`, and
`s[i] == 'D'` if `perm[i] > perm[i + 1]`.
Given a string param_s, reconstruct the permutation `perm` and the result is it.
If there are multiple valid permutations perm, the result is any of them.
Example 1:
Input: s = "IDID"
Output: [0,4,1,3,2]
Example 2:
Input: s = "III"
Output: [0,1,2,3]
Example 3:
Input: s = "DDI"
Output: [3,2,0,1]
Constraints:
<code>1 <= s.length <= 10<sup>5</sup></code>
`s[i]` is either `'I'` or `'D'`.
