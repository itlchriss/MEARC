Given a string param_s, find the first non-repeating character in it and the result is its index.
If it does not exist, the result is `-1`.
Example 1:
Input: s = "leetcode"
Output: 0
Example 2:
Input: s = "loveleetcode"
Output: 2
Example 3:
Input: s = "aabb"
Output: -1
Constraints:
<code>1 <= s.length <= 10<sup>5</sup></code>
param_s consists of only lowercase English letters.
