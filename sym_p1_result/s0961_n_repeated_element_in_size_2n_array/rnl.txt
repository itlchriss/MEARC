You are given an integer array param_nums with the following properties:
`nums.length == 2  n`.
param_nums contains `n + 1` unique elements.
Exactly one element of param_nums is repeated `n` times.
Return the element that is repeated `n` times.
Example 1:
Input: nums = [1,2,3,3]
Output: 3
Example 2:
Input: nums = [2,1,2,5,3,2]
Output: 2
Example 3:
Input: nums = [5,1,5,2,5,3,5,4]
Output: 5
Constraints:
`2 <= n <= 5000`
`nums.length == 2  n`
<code>0 <= nums[i] <= 10<sup>4</sup></code>
param_nums contains `n + 1` unique elements and one of them is repeated exactly `n` times.
